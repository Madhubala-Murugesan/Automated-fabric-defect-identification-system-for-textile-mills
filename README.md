# Batch 3 — Automated Fabric Defect Identification System for Textile Mills

> L&T EduTech Internship | Batch 3 

---

## 📌 Project Overview

Modern textile mills operate high-speed weaving and finishing lines that produce
large volumes of fabric across different textures, colors, and weave patterns.
Manual inspection is prone to fatigue and inconsistency, leading to missed defects,
export penalties, and quality-related losses.

This project builds a **computer vision-based textile defect detection system** using:
- **Roboflow** — for fabric image annotation
- **Python** — for real-time inference pipeline
- **Power BI** — for defect analytics and quality dashboard

---

## 🎯 Objective

Design and develop an automated fabric inspection system that:
- Identifies surface defects in real time
- Classifies defects (weaving errors, thread breaks, stains, holes)
- Provides continuous quality monitoring across textile production lines
